# Импорт карты DO3OP

Файл `assets/DO3OP_WorldIce.fbx` — единый экспорт ландшафта из `Ko3bIrb/DO3OP/godot/assets/models/world_ice.glb`.

После импорта в Roblox Studio проверьте карту в режиме редактирования, без Play. Если Studio предложит настройки, оставьте масштаб по умолчанию и включите импорт материалов. Закрепите импортированную модель (`Anchored`) и сохраните place.
