# Импорт полной карты DO3OP

`assets/DO3OP_WorldIce.fbx` — единый FBX-экспорт из исходного Godot-мира. Внутри запечены базовая геометрия, облегчённые деревья и камни из `data/landscapes.json`; Roblox Studio не должна запускать Lua для их отображения.

После импорта проверьте в Explorer, что вся модель находится внутри `Workspace/WorldIce`. Для свободной камеры используйте режим редактирования, не Play.
