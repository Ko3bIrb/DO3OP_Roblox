# DO3OP Map — прототип ландшафта

Это чистая новая версия проекта. Первый этап содержит только ландшафт:
две непрерывные снежные стороны, прямое русло одинаковой ширины и глубины и водопад. Башен, замков, дорог и игровой логики пока нет.

## Просмотр

1. Запустите `rojo serve` в этой папке.
2. В Roblox Studio откройте Baseplate.
3. Подключите Rojo к `localhost:34872` и нажмите `Sync In`.
4. Нажмите `Play`.

Карта создаётся в `Workspace/MapPrototype`. После визуальной проверки меняем только этот этап.
