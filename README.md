# DO3OP Map — первый статический прототип

В репозитории сейчас только первый этап карты. Ландшафт находится в `Workspace/MapPrototype` и уже сохранён в place-файле: Lua и Play для просмотра не нужны.

## Вариант 1: открыть готовый place

Скачайте `DO3OP_MapPrototype.rbxlx` и откройте его в Roblox Studio. Карта будет видна сразу в режиме редактирования, поэтому можно свободно двигать камеру без Play.

## Вариант 2: синхронизировать через Rojo

```powershell
C:\Rojo\rojo.exe serve
```

Запускайте команду из этой папки проекта. В Studio подключитесь к `localhost:34872` через **Plugins → Rojo → Sync In`. После Sync In карта также будет видна сразу.

## Что входит в прототип

- две большие непрерывные снежные стороны;
- прямое русло шириной 72 studs;
- глубина русла 11.2 studs;
- водопад;
- береговые камни;
- нет башен, точек строительства, дорог, замков и игровой логики.
