# DO3OP Roblox map

В `assets/DO3OP_WorldIce.fbx` находится геометрия карты, экспортированная из исходного Godot-репозитория `Ko3bIrb/DO3OP`. Процедурная плита удалена.

## Импорт в Roblox Studio

1. Откройте Roblox Studio и создайте Baseplate.
2. Выберите **Home → Import 3D**.
3. Укажите `assets/DO3OP_WorldIce.fbx`.
4. Дождитесь импорта и переименуйте полученную модель в `WorldIce`.
5. Оставьте `WorldIce` в корне `Workspace`.
6. Сохраните place как `DO3OP_WorldIce.rbxlx`.

Это текущая геометрия Godot-карты. Точки строительства и замки не редактировались.
