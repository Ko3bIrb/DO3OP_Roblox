# DO3OP Roblox map

`assets/DO3OP_WorldIce.fbx` — полный экспорт зимней карты из репозитория `Ko3bIrb/DO3OP`.
Он содержит authored-ландшафт, реку до границы карты, водопад от вершины горы, деревья и камни из Godot-расстановки с отдельными Roblox-совместимыми цветовыми группами: сине-серый снег, тёмный камень, хвоя, коричневое дерево и бирюзовая вода. Точки строительства и замки оставлены без изменений.

## Импорт в Roblox Studio

1. Скачайте `DO3OP_WorldIce_Import.zip` и распакуйте его. В этой версии три дома с крышами, одна палатка с костром и исправленная мельница.
2. Откройте Roblox Studio и создайте Baseplate.
3. Выберите **Home → Import 3D**.
4. Укажите `assets/DO3OP_WorldIce.fbx`.
5. Дождитесь окончания импорта и переименуйте модель в `WorldIce`.
6. Оставьте `WorldIce` в корне `Workspace`.
7. Временно отключите `CanCollide` только у воды, если Roblox импортировал воду как коллизионную геометрию.
8. Сохраните place как `DO3OP_WorldIce.rbxlx`.

Карта должна быть видна сразу в режиме редактирования, без Play.


## Если FBX импортировался белым

Откройте **View → Command Bar**, откройте файл `ColorizeWorld.lua`, скопируйте его содержимое в Command Bar и нажмите Enter. Скрипт перекрасит уже импортированный `Workspace/WorldIce` в режиме редактирования; Play не нужен.
