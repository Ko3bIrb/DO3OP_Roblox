# DO3OP World — final Roblox files

В репозитории оставлены только финальные файлы карты:

- `DO3OP_WorldIce.rbxlx` — place для открытия в Roblox Studio;
- `DO3OP_WorldIce.fbx` — геометрия для импорта через **Home → Import 3D**;
- `DO3OP_WorldIce_bundle.zip` — оба файла одним архивом.

В RBXLX сохранена пользовательская версия карты с выровненным водопадом и матовой водой без белых отражающих полос.
